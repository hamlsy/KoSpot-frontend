# Regression Baseline Checklist (Web 보호선)

## 목적
- 모바일 구현 중 기존 웹 기능 회귀를 차단하기 위한 기준선 체크리스트

## 인증
- [ ] `/loginPage` 진입
- [ ] OAuth 로그인 성공 후 `/main` 진입
- [ ] OAuth 로그인 실패 시 로그인 페이지 복귀
- [ ] 로그아웃 후 토큰/세션 정리

## 핵심 기능
- [ ] 메인 페이지 렌더링
- [ ] 공지 리스트/상세 진입
- [ ] 싱글 게임 진입
- [ ] 멀티플레이 로비 진입

## 실시간 연결
- [ ] 로그인 후 notification socket 연결
- [ ] 친구 소켓 연결/해제 정상 동작

## 배포 검증
- [ ] `npm run build:prod` 성공
- [ ] S3 배포 후 메인 라우트 접속 정상
- [ ] 캐시 무효화 후 신규 번들 반영 확인
